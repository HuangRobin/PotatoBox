技术支持

需要帮助、报告问题或提出建议，请通过 PotatoBox 的 GitHub Issues 联系开发者。

提交问题或建议 · 查看已有反馈

请提供设备型号、iOS / iPadOS 版本、PotatoBox 版本、操作步骤和出现的问题。可附上不含个人信息的截图。GitHub Issues 为公开页面，请不要发布密码、联系方式或私人文件。提交反馈需要 GitHub 账号。

使用帮助

  • 播放音乐盒：选择纸带，推入把手，向上拨动后松手。
  • 作曲：点按纸带添加或删除音符，组合和弦、调整速度；使用撤销和重做修改旋律，并保存作品。
  • 导入 MIDI：在作曲工具中选择 MIDI，通过系统文件选择器打开文件。支持以拍为单位的 MIDI 0/1 格式，文件大小最多 10 MB。
  • 后台播放：可通过系统播放控件暂停或继续。
  • 作品保存在设备上。删除 App 前请保留需要的文件；如遇读取错误，请先保留原文件，再提交反馈。

Technical support

For help, bug reports or suggestions, contact the developer through PotatoBox GitHub Issues. You can also browse existing reports.

Include your device model, iOS / iPadOS version, PotatoBox version, steps to reproduce and what happened. Screenshots should not contain personal information. Issues are public, so do not post passwords, contact details or private files. A GitHub account is required to submit a report.

Using PotatoBox

  • Select a paper strip, push in the handle, flick upward and release to play.
  • Tap the paper strip to add or remove notes, combine chords, adjust the tempo, refine with undo and redo, and save your work.
  • Choose MIDI in the composition tool and select a file with the system file picker. Beat-based MIDI format 0 and 1 files up to 10 MB are supported.
  • Use system playback controls to pause or resume background playback.
  • Works are stored on your device. Keep copies of files you need before deleting the app. If a file cannot be read, preserve the original before reporting the problem.
